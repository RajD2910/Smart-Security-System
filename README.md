# Smart Security & Safety System

A multi-functional security system integrating intrusion detection and fire safety using Arduino.

## Features
- Password-protected access
- Three modes: Disarmed, Armed Home, Armed Away
- 24/7 smoke detection
- Admin Menu for secure password reset
- EEPROM-based password storage
- Distinct alarms for fire and intrusion

## Components Used
Arduino UNO, PIR Sensor, MQ-2 Smoke Sensor, Door Sensor, Keypad, I2C LCD, EEPROM

## Future Scope
IoT integration using ESP32/GSM for remote alerts and smart monitoring.
